# AgentLink

在 QQ 群和私聊中提供受限的 AI 对话，内置大肥鱼文字人设。群成员通过 @机器人或 `/chat` 发起提问；每个群拥有独立会话和隔离 Worker。

默认群聊支持联网查询；主人可为指定群分别开启文件和终端。所有工具仍受群级隔离工作区限制，子代理与工作流始终关闭。

## 快速开始

默认 `runtimeMode: auto`：优先启用沙箱；本地环境准备失败时，自动降级为 Node 直连模型的纯聊天模式。

**运行条件：** Node.js 22.12+、AlemonJS 和 QQ Bot 配置。默认无需 Redis、Docker 或 Python，也无需管理员权限。

未配置框架 `db.redis` 时使用本地文件状态库；已有 Redis 配置继续使用 Redis。macOS / Linux 有可用沙箱和 Python 时自动准备 Worker，否则静默进入 Node 纯聊天模式。Windows 原生使用纯聊天；完整 Worker 仍需 WSL2。纯聊天不提供网页、文件或终端工具。

启动前仅需填写本机 `alemon.config.yaml` 的 QQ Bot 和模型凭证，配置示例见 [配置指南](docs/config.md)。

在 `alemon.config.yaml` 的 `alemonjs-agent-link` 中设置 `apiKey`、可选 `baseUrl` 与 `model` 后启动。发送 `/agentstatus` 确认服务已就绪。

## 使用方法

### 私聊设置主人

私聊机器人发送 `/我是主人`，到机器人服务端日志查看 6 位验证码，再私聊回复 `/我的主人 验证码` 或 `/我是主人 验证码`。只有不带参数的 `/我是主人` 会重新申请验证码。验证码仅保存在内存中，5 分钟有效，最多尝试 5 次；重新申请、验证成功或重启服务后旧验证码失效。验证通过后使用框架配置接口将当前用户加入 `master_key`，保存到 `alemon.config.yaml` 并立即生效，保留已有主人。

### 群成员

| 操作           | 用法                                                       |
| -------------- | ---------------------------------------------------------- |
| 提问           | `@机器人 帮我总结刚才的讨论` 或 `/chat 帮我总结刚才的讨论` |
| 取消自己的请求 | `/cancel`                                                  |
| 查看服务状态   | `/agentstatus`                                             |
| 查看隐私说明   | `/agentprivacy`                                            |
| 查看帮助       | `/agenthelp`                                               |

普通群消息不会单独触发模型；它们会在短时间内作为下一次提问的参考。默认保留最近 20 条、15 分钟，且会被压缩后提供给模型。

### 群管理员或机器人主人

| 操作         | 用法                  | 影响                       |
| ------------ | --------------------- | -------------------------- |
| 开始新话题   | `/new`                | 清除本群正式会话和短时参考 |
| 调整工具权限 | `/agentpolicy web     | files                      | terminal on | off` | 变更当前群的能力并开始新会话 |
| 预览参考摘要 | `/agentcontext`       | 不修改数据                 |
| 清除参考摘要 | `/agentcontext clear` | 保留正式会话               |

### 机器人主人（私聊）

| 操作               | 用法                                                                 |
| ------------------ | -------------------------------------------------------------------- |
| 配置模型凭证       | 修改 `alemon.config.yaml` 的 `alemonjs-agent-link.apiKey` 后重启     |
| 查看模型           | `/agentmodels`、`/agentmodel`                                        |
| 查看完整状态       | `/agentstatus`                                                       |
| 私聊使用 Agent     | 直接发送文字，或 `/chat 你的问题`                                    |
| 彻底删除指定群数据 | 在目标群中执行 `/agentpurge`，再于 60 秒内执行 `/agentpurge confirm` |

## 运行模型

```text
QQ / AlemonJS
  → 本地文件状态库 / Redis：去重、限流、会话代际、短时上下文
  → Node 编排：群内串行、全局并发控制
  → 本机 Bridge：鉴权与受限模型代理
  → 每群 sandbox Worker：DSH chat-only 会话
```

AgentLink 仅支持**单 Node 进程**连接同一个 QQ 机器人。不要同时启动多个副本；分布式协调尚未实现。

主人私聊支持直接发文字、`/new` 清空会话、`/cancel` 取消请求。纯聊天模式默认保留最近 10 轮私聊历史，最多 24 小时。普通用户私聊默认关闭，可通过 `privateChatAccess: all` 开放，且只允许聊天。详见[大肥鱼与私聊配置](docs/config.md#大肥鱼与私聊)。

群里也可发送“大肥鱼，今天好累”唤醒。私聊支持 `/记住 内容`、`/记忆`、`/忘记 编号`、`/忘记全部`，管理自己的长期资料。能力对标与下一步验收见[大肥鱼能力差距](docs/dafeiyu-roadmap.md)。

图片默认使用 DSH 当前模型识别，无需独立识图服务。语音输入、`/语音 问题` 和 `/表情 标签` 已提供配置入口，见[媒体能力](docs/media.md)。未配置的输入能力会按角色回复“看不懂，就当是夸我了”。
