# 智能体连接

**会聊天、能查网页、记得住事，也守得住边界。**

QQ Bot / OneBot 11 · Node.js 22.13+ · DSH 沙箱会话 · 单进程 · MIT

[如何本地启动](#如何本地启动) · [运行模型](#运行模型) · [能做什么](#能做什么) · [命令速查](docs/commands.md) · [文档首页](docs/README.md) · [配置指南](docs/config.md)

</div>

在群里 @ 它、喊一声“肥鱼”，或者直接 `/提问`，就能收到一段带上下文、会用工具的回答。每个群有自己的会话、Worker、工具权限和额度；私聊里它记得你说过的事。

AgentLink 是 AlemonJS 插件：消息编排、状态库、预算、工具权限都在 Node 里，模型执行交给本机 DSH Worker，每个群一份独立的沙箱与人格。

> **项目状态：可用，但边界明确。** 代码路径、模拟收发和本地状态已有测试覆盖；真实 QQ 收发、群管理权限与部分外部服务仍要在你的账号上验收，见[能力建设与验收](docs/capabilities.md)。只支持**一个 Node 进程**连接同一个机器人，暂不支持多副本。

## 运行模型

![AgentLink 运行模型：QQ 接入、Node 编排、本机 Bridge、每群 Worker](docs/assets/architecture.png)

```text
QQ / OneBot 11
  → Node 编排：去重、限流、会话代际、群内串行
  → 本机 Bridge：临时令牌鉴权，限制体积，Worker 拿不到真实 Key
  → 每群 Worker：DSH chat-only 会话，独立 home 与沙箱
```

沙箱未就绪时自动降级为纯聊天，并在后台按 30 秒至 5 分钟退避重试；网页工具等沙箱恢复后再开放，终端对所有身份始终禁止。完整拆解见[架构与开发](docs/architecture.md)。

## 群聊里它怎么接话

- **明确找它**：@ 机器人、`/提问`、引用它的消息，或说“肥鱼，帮我……”——一定进入回答流程；句首直接叫名字、引用它的消息不再等待分类模型。
- **普通讨论**：默认用 `groupChat.activity: active` 的积极节奏，除呼唤与话题续接外，允许模型判断是否适合加入当前公开闲聊；不会仅因消息有用、有人报错就插话。安静与均衡模式仍以呼唤和话题续接为主。再叠加冷却与每小时上限；不想开放时设 `groupChat.enabled: false`，@ 与命令仍可用。
- **怎么合并**：短暂停顿 1.2 秒后回复，持续发言时最多聚合 4 秒；近期参考默认保留最近 20 条、15 分钟，压缩后提供给模型。
- **不会无限接**：同一发送者重复内容、机器人互聊迹象与突发刷屏有本地熔断；判断本身不启动沙箱，也不写模型会话。

细节与每个参数的默认值见[群聊参与策略](docs/config.md#群聊参与策略)。

## 如何本地启动

### 1. 安装 Git 和 Node.js

先安装 **Git** 和 **Node.js 22.13+**（包含 npm）。Git 可从 [Git 下载页](https://git-scm.com/downloads) 获取，Node.js 可从 [Node.js 下载页](https://nodejs.org/en/download) 获取。安装后重新打开终端，检查版本：

```bash
git --version
node --version
npm --version
```

macOS 也可以运行 `xcode-select --install` 安装包含 Git 的命令行工具；Ubuntu / Debian 可使用 `sudo apt update` 后执行 `sudo apt install git`。Windows 若需要完整沙箱工具能力，请在 WSL2 内安装 Git、Node.js 并执行后续步骤，详见 [平台支持](docs/operations.md#平台支持与部署前检查)。

### 2. 使用 Git 下载代码

在准备存放项目的目录打开终端：

```bash
git clone https://github.com/xiuxianjs/alemonjs-agent-link.git
cd alemonjs-agent-link
```

后续命令都在这个仓库目录内执行。

### 3. 安装依赖并构建

```bash
npm install
npm run build
```

默认使用本地状态存储，无需单独安装 Redis。增强工具能力需要的环境及限制见 [运维手册](docs/operations.md)。

### 4. 生成并填写配置

```bash
npm run init
```

命令会显示 `alemon.config.yaml` 的绝对路径。打开该文件，在已有配置段中填写自己的模型 API Key：

```yaml
alemonjs-agent-link:
  apiKey: '<MODEL_API_KEY>'
```

将 `<MODEL_API_KEY>` 替换为实际密钥，保留配置中的其他字段，不要重复添加同名 YAML 段。默认使用 DeepSeek；其他模型服务的配置见 [配置指南](docs/config.md)。

### 5. 检查并启动

```bash
npm run doctor
npm start
```

离线检查通过后启动。QQ 凭证留空时，按终端提示扫码授权；已有 AppID 与密钥可直接填入配置。群里 @ 机器人或私聊 `/提问 你好`，发送 `/状态` 查看实际运行情况。按 Ctrl+C 停止，后续启动直接执行 `npm start`。

配置与数据默认保存在固定用户目录；检测到仓库内已有配置或数据时会沿用。命令输出的配置路径为准。需要将配置与数据放在当前目录时，生成、检查和启动都使用 `--portable`：

```bash
npm run init -- --portable
npm run doctor -- --portable
npm start -- --portable
```

指定已有配置可使用 `npm start -- --config /absolute/path/alemon.config.yaml`。

已有 AlemonJS 宿主的插件安装方式见 [运维手册](docs/operations.md#插件安装)。

> **第一次设置主人**：私聊机器人发送 `/我是主人`，到服务端日志查看 6 位验证码，再私聊回复 `/我的主人 验证码`。验证码仅存内存、5 分钟有效、最多尝试 5 次。验证通过后写入 `master_key`，群管理、模型与额度命令才会生效。

## 数据与安全

- **默认开放**：聊天、网页查询、会话目录内的文件、长期记忆、主动搭话、自动语音与表情、B 站阅读、QQ 空间读取。
- **始终禁止**：终端，包括主人；配置和策略命令都不能重新开启。
- **文件边界**：只能访问当前会话分配目录内的相对路径，拒绝穿越、绝对路径、符号链接与硬链接。
- **状态与清理**：默认本地文件状态库，检测到框架 `db.redis` 时继续使用 Redis；群 Agent 数据无活动 30 天后清理，`/清除群数据` 需 60 秒内二次确认。
- **凭证**：`alemon.config.yaml` 必须留在版本控制之外；日志不记录用户请求、模型输出与 Key。

详见[安全与数据](docs/security.md)。

## 状态与已知边界

- **单进程**：缺少分布式租约，多副本会破坏群内顺序、取消和首次隔离迁移。
- **平台条件**：macOS 需要 `sandbox-exec`，Linux 需要 Bubblewrap，Windows 走 WSL2 运行完整服务；缺依赖时降级为纯聊天。[平台支持](docs/operations.md#平台支持与部署前检查)
- **尚未全量验收**：真实 QQ 附件与 GIF 抽帧、引用与转发、群管理执行回执、语音与生图服务、语义召回的实际嵌入服务、B 站评论/回复读取与空间发布，都要在自己的账号与网络下复核；[能力表](docs/capabilities.md)逐项标注。
- **第三方与费用**：OneBot 网关、模型服务与生图服务由你自行选择，可能单独计费或调整额度；仓库不承诺免费或长期兼容。
- **信号风控**：使用账号协议接入时，平台风控与账号风险由使用者承担，建议先用测试账号和小范围群。
